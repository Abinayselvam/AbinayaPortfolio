# AbinayaPortfolio

Abinaya S | Portfolio Web Application
A modern, full-stack personal portfolio application designed to showcase my skills, projects, and experience as a Full Stack Developer. Built with a focus on clean architecture, responsive design, and seamless user experience.

Tech Stack
Frontend:

Framework: Angular 17+ (Standalone Components)
Language: TypeScript
Styling: SCSS, Tailwind CSS (Utility classes)
State/Reactivity: RxJS, Reactive Forms
Backend:

Framework: .NET 8 (ASP.NET Core Web API)
Language: C#
ORM: Entity Framework Core
Database: SQL Server / SQL Server LocalDB
